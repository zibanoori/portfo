# Ziba Noori - Personal Portfolio Website

Welcome to my personal portfolio website!

This project showcases my journey as a developer with a frontend background and a growing focus on Python and Django backend development.

The website is designed with a clean, modern, and professional style while keeping the user experience simple and accessible.

## 🌐 Live Demo

[Visit the Website](https://zibanoori.github.io/ziba-noori-portfolio/)

## 🚀 Features

- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Modern UI:** Clean layout with a simple and professional visual style.
- **Hero Section:** Introduction and professional profile.
- **About Section:** Information about my development journey.
- **Skills Section:** Technologies and tools I am currently working with.
- **Projects Section:** A showcase of my development projects.
- **Contact Section:** A way for visitors to get in touch.
- **Social Links:** GitHub and LinkedIn profiles.

## 🛠️ Technologies Used

- **HTML5:** Semantic structure for the website.
- **CSS3:** Custom styling, CSS Variables, Flexbox, and Grid.
- **JavaScript:** Interactive functionality.
- **Font Awesome:** Icons and UI elements.
- **Google Fonts:** Rubik, Oswald, Outfit, and Dancing Script.

## 🎨 Design

The website uses a cool and minimal color palette based on navy blue, soft blue, and light backgrounds.

The goal is to create a professional portfolio that is simple, elegant, and easy to navigate.
